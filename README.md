# AffectFusion — Thesis Showcase Website

Interactive editorial project showcase for **AffectFusion: A Cross-Attention Transformer Framework for Explainable Multimodal Emotion Recognition from Text and Emoji Semantics** (Phase-I Thesis, Department of Computer Science and Engineering, Daffodil International University).

- **Live Website (GitHub Pages):** `https://ragibcs.github.io/affectfusion.site/`
- **Hugging Face Dataset (DOI):** [https://doi.org/10.57967/hf/11874](https://doi.org/10.57967/hf/11874) ([ragibhasan/AffectFusion](https://huggingface.co/datasets/ragibhasan/AffectFusion))
- **Zenodo Archive:** [https://zenodo.org/records/24543680](https://zenodo.org/records/24543680?preview_file=affectfusion_dataset_v1.0.0.zip) (`10.5281/zenodo.24543680`)
- **Main Thesis Codebase:** [https://github.com/ragibcs/AffectFusion](https://github.com/ragibcs/AffectFusion)

## Local Preview
Open `index.html` directly in any browser, or run:
```bash
python3 -m http.server 8080
```

## Enable GitHub Pages
After pushing to `main`, open **Settings → Pages → Build and deployment**, set **Source** to `Deploy from a branch`, select **`main` / `/ (root)`**, and save.
